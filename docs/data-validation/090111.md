## Classification evidence

The [Census reference index](https://www.census.gov/foreign-trade/reference/index.html) supplies annual import and export concordances. All twelve retained 2021–2026 files were checked against their previously recorded SHA256 hashes, then independently extracted for 090111. The [evidence extract](090111-classification-evidence.json) records each source URL, digest, code and description. The original files remain in ignored `data/raw/classification-090121/`; these are complete annual concordances, not coffee-only extracts.

All six annual export schedules preserve the same 0901110000 definition: [2021](https://www.census.gov/foreign-trade/schedules/b/2021/c09.html), [2022](https://www.census.gov/foreign-trade/schedules/b/2022/c09.html), [2023](https://www.census.gov/foreign-trade/schedules/b/2023/c09.pdf), [2024](https://www.census.gov/foreign-trade/schedules/b/2024/c09.pdf), [2025](https://www.census.gov/foreign-trade/schedules/b/2025/c09.pdf), [2026](https://www.census.gov/foreign-trade/schedules/b/2026/c09.pdf). Each annual import description remains within non-roasted, non-decaffeinated coffee, including organic, Arabica and other species detail.

Import concordances have four matching entries in 2021–2024 and eight in 2025–2026. They are reference snapshots, not calendars of simultaneously active codes. The [USITC July 1, 2025 change record](https://www.usitc.gov/tariff_affairs/documents/484%28f%29_committee_changes_for_july_1_2025-final.pdf), pages 1–2, splits 0901110045 into 0901110035/0901110050 and 0901110055 into 0901110040/0901110065. Every transfer stays within 090111. The reviewed [January/February 2026](https://www.usitc.gov/tariff_affairs/documents/list_of_committee_changes_for_january-1-2026-and-february-1-2026.pdf) and [July 2026](https://www.usitc.gov/tariff_affairs/documents/list_of_committee_changes_for_july_1_2026-final.pdf) change records have no 0901.11 match.

This supports a comparable **six-digit interval from September 2021 through August 2026** in both directions. We use the Census HS6 aggregate, without summing retired and replacement detailed codes. This review does not establish unchanged tariffs, reporting completeness, stable revisions or actual duties paid. It does not exhaustively inspect every historical intrayear HTS edition.

The [interval file](../../data/classification/090111.json) supplies this bounded evidence to the existing importer. Earlier reporting months clip its end; later months do not extend it. Missing source observations remain unavailable. Product publication and duty acceptance require their own source and browser checks.
