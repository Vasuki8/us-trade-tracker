# Coffee data verification

Status: **Live verification pending.** All versioned application data currently consists of clearly labeled synthetic test fixtures.

The owner chose to keep `CENSUS_API_KEY` in a GitHub Actions repository secret. The manual import workflow will retrieve public observations and produce a downloadable release artifact. Never put the key in Git, a GitHub variable, an artifact, browser code, request logs, or this document.

Before calling this milestone complete, record five actual source values spanning imports, exports, world and country observations; their sanitized queries, reporting month, retrieval time and processing commit; two independently checked trailing twelve-month totals; and one partner share. Verify the response's aggregate filters against Census before accepting it.

Classification continuity must be reviewed independently of the response's description. The [2021 Schedule B chapter](https://www.census.gov/foreign-trade/schedules/b/2021/c09.html) and [2022 chapter](https://www.census.gov/foreign-trade/schedules/b/2022/c09.html) both list 0901.21 under roasted coffee, not decaffeinated. These two references alone do not validate all intervening years, current imports, or the entire requested history. No real classification interval is asserted yet. Supply reviewed intervals through `--classification path.json`, as an array of `{ "from": "YYYY-MM", "to": "YYYY-MM", "evidenceUrl": "https://official-reference" }`. Adjacent incompatible intervals stay separate. Without evidence, the application labels classification continuity unverified and does not calculate cross-period growth.

A successful mocked refresh verifies recovery and revision detection. It does not replace verification across two successive official monthly releases.
