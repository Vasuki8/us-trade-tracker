# Coffee estimated-duty validation

The approved scope is HS 090121, September 2024–August 2026. **The 24-month live audit, version 2 archive recovery and displayed comparisons are verified.** Independent calculation and UI reviews found no material defects. [PR #10](https://github.com/Vasuki8/us-trade-tracker/pull/10) contains the profile integration; the separate audit does not promote a release.

The manual **Audit product estimated duties** workflow (originally **Audit coffee estimated duties**) uses the existing GitHub `CENSUS_API_KEY` secret and reads four summary levels for each of 24 months: `HS`, `HSCY`, `HSRP` and `HSCYRP`. It requests `CAL_DUT_MO`, `CON_VAL_MO` and `DUT_VAL_MO`. It does not use R2 credentials or change an accepted release or archive pointer. Product selection now defaults to `090121` and must pass the reviewed, importable registry before retrieval; new coffee artifacts are named `census-090121-duty-audit` and scoped to `.tmp/duty-audit/090121/`. Historical evidence below keeps its original name and bytes.

The artifact retains sanitized query definitions, retrieval time, exact response payloads, per-file SHA-256 digests, an unpromoted duty dataset and an audit report. A failed month remains visible in that report. Existing audit output must be retained separately; reruns require a fresh output directory. Auditing an unpublished product is permitted before duty acceptance, but `eligibleForRelease` only records this audit's coverage/reconciliation checks; it does not grant publication, verify classification evidence or promote a release. The generic path has been tested with a synthetic second product; this does not establish another product's live Census coverage.

Acceptance checks each available national and country measure against its disjoint rate-provision records, excludes country groupings, and compares individual-country sums with national totals. Where a measure's country breakdowns are available and their totals match the nation, its rate-provision component sums must also match. An unrelated missing measure cannot hide a discrepancy in a reported measure. Missing values and absent country months stay unavailable. Unknown dollar markers, duplicate dimensions and inconsistent totals cannot qualify a release.

RP70/79 dutiable amounts are retained even when their calculated-duty amounts are reported as zero. An absent or incomplete breakdown makes coverage unavailable. A positive affected amount qualifies a reported figure; it does not establish duty-free imports or actual duties paid.

Sources: [Census imports variables](https://api.census.gov/data/timeseries/intltrade/imports/hs/variables.html), [query guide](https://www.census.gov/foreign-trade/reference/guides/Guide_to_International_Trade_Datasets.pdf), [rate-provision definitions](https://www.census.gov/foreign-trade/reference/rpcodes.html), [duty methodology](https://www.census.gov/foreign-trade/guide/sec2.html).
