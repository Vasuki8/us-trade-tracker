### Harness safeguards required before real operations

- Admit each real attempt into an exclusive durable operation ledger **before launching**, with role, allowance number, fresh output, frozen bundle, launch identity and time budget. Count failures and uncertain/missing completion receipts as spent attempts. Do not count only completed receipt files. A failed admission cannot launch a worker.
- Reuse the native guardian with its retained process handles and Job Object membership. Drain stdout/stderr with an enforced **1 MiB combined cap during execution**, not after an unbounded `communicate()`. Audit events are likewise bounded during collection. A lost guardian, missing trace, log overflow, unknown ownership or unverified cleanup cannot establish success.
- Instrument actual data opens and writes, including the isolated input root, numeric descriptors/returned handles, staging/hard-link/unlink paths and resolved aliases. Permit only exact input files, frozen code/loader assets and the invocation's fresh output/log targets. Successful historical reads, denied attempts and owned output readbacks have separate counts. Do not equate a denied-read counter with proof of successful-read coverage.
- Deny source/network/provider access and unapproved child/worker launch paths. Preparation may run only its existing read-only Git HEAD query. Trace the actual dependency graph and test the filesystem/transport/process entrypoints it uses. Capture bounded transport call names and non-secret target arguments; classify local named pipes separately from outbound attempts. Do not infer harmless pipes from a count of two. Any unexpected outbound attempt fails verification even if application code catches the denial.
- Synthetic controls use fake contained data/sentinels, never actual excluded bodies. These are application-level controls for the frozen trusted graph, not a universal same-user/kernel sandbox or a power-loss durability certification. Keep uncertain `publicationState:"may-be-visible"` outcomes unsuccessful; do not assert an absent receipt when rollback was impossible.
