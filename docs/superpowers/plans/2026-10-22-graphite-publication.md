## Intent and recommendation

The requested outcome is the compact dashboard, shared navigation/search and persistent light/dark themes becoming public while keeping the pilot's figures, sources, qualifications, saved views and downloads trustworthy. Content should remain concise. Success requires local package acceptance, an observed Production assignment, matching live bytes/headers, useful browser journeys and truthful cleanup records.

**Recommended:** build and authenticate one new package from the reviewed merge, then use the existing manual Direct Upload flow. Restore the exact retained four-product package on regression before attempting one bounded repair. Reusing an unmanifested local preview would omit deployment controls and provenance; introducing automated deployment or public R2 would add an unnecessary system. Neither alternative is included.
