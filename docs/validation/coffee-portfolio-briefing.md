# Coffee portfolio briefing verification

The approved batch adds `/briefing/portfolio/` for the published coffee profiles. Select one or both products and Imports/Exports, share the validated selection URL, generate two sourced CSVs in the browser, or print the selected report. Products retain separate figures and duty denominators; the report has no combined portfolio total or averaged duty rate.

The reporting month is the newest selected release. An older selected release has an explanatory notice and blank comparison amounts in the summary CSV; selecting it alone restores its own periods. Missing/suppressed figures, classification boundaries, zero prior values and uncalculated-duty coverage retain their existing meanings. Exports contain no U.S. estimated duties. No raw observation/history arrays or browser Census requests are introduced.
